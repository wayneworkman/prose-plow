# Python packages for the host build, the model converters and the reference-data generators.
# Every version is exact: this is the set the build, the conversions and the tests were verified
# with (CPython 3.12.3, GCC 13.3.0, Linux x86_64). Install into a virtualenv of your own:
#
#   pip install -r native/requirements.txt
#
# torch comes from the CPU-only index: nothing here uses a GPU, and the default wheel would pull
# several gigabytes of CUDA libraries.

# The converters: llama.cpp's conversion framework imports torch and transformers; the peacebell
# converter parses the SentencePiece model with sentencepiece and protobuf; the boris2 and shard2
# converters read tokenizer.json with tokenizers; upstream's converter, which converts Qwen,
# loads the tokenizer through transformers (which files it reads, and so the output, depend on
# this version). The reference-data generators run the PyTorch reference models with the same
# torch. The Shard-2 checkpoint is a pickle and is only ever read with torch.load(...,
# weights_only=True), which this torch version supports for it as it is.
